# 심사 시연 대본 (Demo Runbook)

> 목표: **5분 안에** "회의 한 장 → 화면 → 계약 → 명세 → 코드"의 근거 사슬을 보여준다.
> 핵심 메시지: *화면에 없는 것은 명세에 없고, 명세에 없는 것은 코드에 없다.*

## 사전 준비 (시연 30초 전)
```bash
npm run dev:server      # :3000
npm run dev:dashboard   # :5173
```
- 브라우저 **http://localhost:5173** 열기. 기본 = 고객 모드.
- `.env`에 `ANTHROPIC_API_KEY` 설정 확인(없으면 파이프라인 멈춤).
- 좌측 대화 패널에 **시드 녹취(태스크 상세)**가 이미 로드되어 있음 — 그대로 써도 되고, 다른 도메인을 원하면 템플릿에서 교체.

---

## 파트 1 — 고객 원클릭 (2분) : "누구나 한 번에"

1. **템플릿 소개** — 헤더 **🗂 템플릿(T)** 클릭. 서로 다른 3개 도메인 회의가 있음을 보여준다:
   - ✅ 태스크 상세(생산성) · 📦 주문 상세(커머스) · 🩺 진료 예약(헬스케어).
   - **📦 주문 상세**를 고른다(시드와 다른 도메인이라 "아무 회의나 된다"가 부각됨).
2. **좌측 대화 패널**을 짚으며: "이게 실제 회의 녹취입니다. 발언자별로 요구가 흩어져 있죠."
3. **🪄 목업 생성(C)** 클릭. 상단 진행 칩을 가리키며 설명:
   - **①요구정리** — 발언을 요구사항 정의서로 압축(capture).
   - **②목업생성** — 요구서로 화면 HTML을 그림(mockup).
   - **③API명세** — 화면을 계약으로 확정하고 명세까지 도출(freeze→reverse).
4. 완료되면 자동으로 **명세(spec)** 뷰가 뜬다. `R`→요구서, `M`→목업, `A`→명세로 전환하며 보여준다.

**👉 근거사슬 강조 포인트 ①**
요구서(`R`)의 각 항목에 붙은 **`[근거: u-NNN]`** 태그를 짚는다.
"이 요구는 상상이 아니라 몇 번째 발언에서 나왔는지가 다 적혀 있습니다." (C-3 · 근거 없는 생성 금지)

---

## 파트 2 — 개발자 6뷰 (2분30초) : "계약이 진실의 원천"

`D` 키로 **개발자 모드** 진입. 헤더 단계 버튼을 왼쪽부터 순서대로 누른다.

1. **② Freeze** 클릭 → **contract** 뷰. Visual Contract YAML 원문을 보여준다.
   **👉 근거사슬 강조 포인트 ②**
   "이건 LLM이 지어낸 게 아니라, 목업 HTML의 좌표·역할·데이터 바인딩을 **기계가 읽어** 만든 계약입니다.
   같은 화면이면 언제 눌러도 **같은 계약**이 나옵니다." (C-1 · freeze 결정적)
   - 실증: **② Freeze**를 한 번 더 눌러 동일 YAML이 나옴을 보인다.

2. **③ 역도출** 클릭 → **spec** 뷰. SRS·ERD·OpenAPI가 표로 나온다.
   **👉 근거사슬 강조 포인트 ③**
   "명세는 **계약만** 보고 만듭니다. 녹취를 다시 읽지 않아요. 화면에 있는 필드·액션만 명세가 됩니다." (C-2)

3. **④ 코드생성** 클릭 → **code** 뷰. 생성된 3파일(칩)과 코드 본문.
   "명세에 있는 객체·엔드포인트가 그대로 코드가 됩니다. 사슬의 끝입니다."

4. **versions** 뷰. 목업 버전 이력(✨신규 / ✏수정)을 보여주며:
   "요구가 바뀌면 전면 재생성이 아니라 **변경분만 델타로** 반영됩니다." (C-4)

---

## 파트 3 — 마무리 (30초)
- 좌→우 한 줄로 정리: **녹취 → 요구서(근거태그) → 목업 → 계약(결정적) → 명세(계약만) → 코드**.
- 한 문장: *"어느 코드 한 줄도, 거슬러 올라가면 회의의 어느 발언에서 왔는지 말할 수 있습니다."*

## 백업 플랜 (라이브 실패 시)
- LLM 지연/오류로 잡이 멈추면: 이미 만들어진 최신 **versions** 항목을 클릭해 목업을 띄우고,
  `contract`/`spec` 뷰에 남아 있는 직전 산출물로 사슬을 설명한다.
- 네트워크 문제면 **⛶ 최대화(F)**로 목업 프리뷰만 크게 보여주고 근거 사슬은 구두로 설명.
